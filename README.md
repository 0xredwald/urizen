# URIZEN

Public homepage / marketing site for **URIZEN** — the flagship autonomous onchain fund on [CTRL](https://github.com/daxaur).

> *Capital has become autonomous.*

## What this is

URIZEN is the first autonomous onchain fund launched through CTRL — the automation layer on Base. An AI trading agent runs an onchain strategy from a non-custodial vault (can-trade, **cannot-withdraw**), and the token buys itself back from real profits + fees.

This repo is the **public marketing site** only. It lives outside any wallet gate.

## Design direction

Lead with the URIZEN brutalist identity, bridge into restrained product chrome:

- **Monochrome** grey/black grainy backdrop, stark heavy sans wordmark
- **One signal color: red** (the angular mark)
- Imagery: industrial / telecom towers, fog, film grain, high contrast
- Voice: terse manifesto — anti-hype, serious, inevitable

## Hard rules

- Public marketing pages only — no wallet gate.
- Never commit secrets. Preview deploys only (no `--prod` unless asked).
- Don't claim traction numbers we don't have. **True:** live on Base, non-custodial, bootstrapped. Specific volume/user numbers are **not** — leave out or mark TBD.
- URIZEN = the flagship fund/token (formerly WORKA). CTRL = the platform.
